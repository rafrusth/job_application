# PathFinder 👔

Website ini bertujuan untuk membantu orang-orang dalam mendapatkan pekerjaan. Fitur yang ditawarkan fokus pada persiapan dan kompetensi orang semata, bukan mencarikan pekerjaan otomatis.

## Tech Stack 🛠️

**Frontend:** Blade (HTML/CSS)

**Backend:** Laravel (PHP)

**Database:** PostgreSQL

**Deployment:** Render
